# Catacomb

A gothic crimson-and-black file browser for the files on your iPhone (not a NAS client).

- Browses the app's own Documents folder (shown in the Files app under On My iPhone > Catacomb)
- Add any folder from Files (iCloud Drive, other apps) as a granted location, kept as a security-scoped bookmark
- Sort, search, breadcrumbs, multi-select, new folder / text file, rename, move, copy, delete, share, import
- Quick Look preview (images, PDF, etc.) and an editor for text, Markdown and JSON

Build: drop this folder into the Stark IPA Builder; project.yml is turned into an unsigned IPA by the Codemagic workflow.
