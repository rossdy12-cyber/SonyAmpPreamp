Racebolt Test 1.1.1 build 3 — LIVE SITE SAFETY STARTUP CORRECTION
Bundle: com.rossdymond.racebolttest

UNSIGNED TEST IPA. Requires separate development signing before installation.
This compile/package script does not upload, sign or publish an app.

Build 2 contained unsupported regex alternation in its WebKit network rules.
Build 3 splits those into separate compatible patterns without removing guards.
The M2 build now checks rule compilation with actual macOS Apple WebKit first;
failure exports a build log only. iPhone startup still fails closed, but now
displays its exact resource/JSON/regex/WebKit error instead of a generic message.
macOS/iOS native checks have NOT been executed by the Linux sandbox.

The WKWebView now loads https://raceboltuk.com/ and its real mobile pages:
motorcycle selector, measuring guide, blog, catalog, accounts and basket.
Internet required. Site cookies/storage persist. Account/contact/subscription
and basket changes are real website actions, not local demo actions.

Checkout/payment routes are guarded by native navigation checks, a compiled
WKContentRuleList installed before loading and document-start JavaScript.
Express-payment buttons and recognised payment/order requests are blocked.
Do not enter card/payment information. This is NOT a server-side sandbox;
unknown or future plugins/payment routes require reviewing the safeguards.
If native safety setup fails, the app refuses to load the site.

The original offline www/ assets are retained but are not the active native UI.
Native Pages shortcuts open Home (motorcycle selector), measuring guide, blog,
Technical, Basket and My account. External top-level links/Safari/payment apps
and downloads are disabled, which can limit external authentication and links.

No credentials, native provisioning profile, certificate or original app binary
are included in the source. No remote build, device install or device launch was
performed for this revision in the Linux sandbox. Chromium guard/read-only live
browsing and mocked build tests passed; actual Apple content-rule compilation,
remote native build and iPhone feature checks are still required. No login,
live basket mutation, order or payment was submitted during testing.
